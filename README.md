# 나를 닮은 식물

관엽식물 판매 회사의 홍보용 모바일 웹페이지. 서버 없이 정적 페이지로 만들고 GitHub Pages에 올립니다. 프로젝트 규칙은 `CLAUDE.md`에 있습니다.

## 로컬에서 보기

```
docker compose up -d        # http://localhost:8080
docker compose down         # 끄기
docker compose run --rm test   # 단위 테스트 (node:20-alpine)
```

## 계산 방식과 출처

- **오행**: 출생연도 끝자리로 정합니다(0·1 금, 2·3 수, 4·5 목, 6·7 화, 8·9 토).
- **띠**: 양력 생일을 브라우저의 중국력(`Intl.DateTimeFormat('en-u-ca-chinese')`)으로 음력 해로 바꿔 정합니다(음력 설 기준). 별도 표나 라이브러리는 쓰지 않습니다. 브라우저가 중국력을 지원하지 않으면 양력 연도로 대신합니다.
- **일진**: 라이브러리 없이 직접 계산합니다(`assets/js/calc.js`). 2000-01-01을 무오일(60갑자 순번 54)로 놓고 날짜 차이를 60으로 나눈 나머지로 구합니다. 같은 날, 같은 띠면 항상 같은 결과입니다.
- **오늘의 운세**: 한마디는 일진 60개, 행운의 색은 일진 천간의 오행, 행운의 시간은 일진 지지의 2시간 구간, 점수는 띠와 일진 지지의 관계(육합·삼합·같음·보통·충)에 따라 `content/fortune.json`의 기본 점수에 일진 순번을 더해 정합니다. 점수 숫자는 임시값입니다.

### 검증 상태

단위 테스트(`tests/calc.test.js`)는 아래 알려진 날짜로 일진과 띠를 확인합니다.

- 일진: 2000-01-01 무오, 1949-10-01 갑자, 2024-02-10 갑진
- 띠(설날 전후): 1984-02-02, 1990-01-27, 2000-02-05, 2020-01-25

위 날짜는 작성자가 알고 있는 값이며 서로 일관되게 맞아떨어지는 것까지만 확인했습니다. **한국천문연구원 자료와의 대조는 아직 하지 않았습니다.** 사람이 대조한 뒤 이 줄을 고쳐 주세요.
